# Gestor de Tareas POO

Gestor de tareas de consola con clase Tarea encapsulada y ArrayList<Tarea>.

## Como se ejecuta

    cd semana03
    javac src/modelo/*.java src/app/*.java
    java -cp src app.GestorTareas

## Que se aprendio

Clases, objetos, constructores, encapsulacion con this, ArrayList<T>
generico y organizacion en paquetes.
